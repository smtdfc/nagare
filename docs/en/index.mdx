**Nagare** (流れ, meaning "flow") is an AI assistant that lives on your computer. Just say what you want — check the machine, open a file, set a reminder, look something up — and Nagare figures out how to do it instead of making you memorize commands.

Nagare runs on Linux, macOS, and Windows. Everything Nagare remembers — conversations, settings, sign-in codes — stays on your machine, in the `~/.nagare` directory.

## What's inside Nagare

You don't need to know these parts to use Nagare, but a quick overview makes the documentation easier to follow:

| Component      | What it does                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| Nagare CLI     | The command-line program that starts Nagare, opens the UI, creates sign-in codes, and checks your machine. |
| Nagare Gateway | The "brain" of Nagare. It runs in the background, answers messages, calls tools, and keeps scheduled jobs. |
| Nagare web UI  | The website where you chat and adjust settings. Open it with `nagare web` at `http://127.0.0.1:3005`.      |
| Nagare Desktop | The same UI, packaged as its own window.                                                                   |
