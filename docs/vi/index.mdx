**Nagare** (流れ, nghĩa là "dòng chảy") là trợ lý AI sống trên máy tính của bạn. Bạn chỉ cần nói mình muốn gì — kiểm tra máy, mở tệp, nhắc việc, tìm thông tin — Nagare sẽ tự tìm cách làm, thay vì bắt bạn nhớ từng câu lệnh.

Nagare chạy được trên Linux, macOS và Windows. Mọi thứ Nagare ghi nhớ — cuộc trò chuyện, thiết lập, mã đăng nhập — đều nằm trên máy bạn, trong thư mục `~/.nagare`.

## Bên trong Nagare có gì

Bạn không cần quan tâm đến những phần này để dùng Nagare, nhưng biết sơ qua sẽ dễ hiểu tài liệu hơn:

| Thành phần     | Nó làm gì                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| Nagare CLI     | Chương trình dòng lệnh để bật Nagare, mở giao diện, tạo mã đăng nhập và kiểm tra máy.                  |
| Nagare Gateway | "Bộ não" của Nagare. Nó chạy nền, trả lời tin nhắn, gọi công cụ và giữ các lịch định kỳ.               |
| Nagare web UI  | Trang web để bạn trò chuyện và chỉnh thiết lập. Mở bằng lệnh `nagare web` tại `http://127.0.0.1:3005`. |
| Nagare Desktop | Cùng giao diện đó, đóng gói thành một cửa sổ riêng.                                                    |
